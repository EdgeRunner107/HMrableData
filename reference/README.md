# 읽기 전용 참고 자료

이 폴더의 원본 관리자 JSX와 H/M 브라우저 테스트는 이전 참고 자료이며 제품 import·빌드·실행 테스트에 포함하지 않습니다.

현재 제품은 원본 UI를 재사용하고 관리자 비밀번호 입력 UI를 제거했습니다. 서버의 기존 Bearer 인증 계약은 유지하며 새 세션의 비밀번호 없는 업로드 인증은 미연결입니다. `PROJECT_REPORT.md`에 제한을 기록했습니다.

테스트는 `npm test`, `npm run test:browser`, `npm run test:mobile`입니다. 실제 H/M 원본은 `../HM-NewData-master`에 변경 없이 보존합니다.
